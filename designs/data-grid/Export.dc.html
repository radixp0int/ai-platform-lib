Scope shows only when it matters. With a selection it defaults to the selected rows. The bulk bar also gets “Export 2 rows”.

The grid doesn't build the file. It calls onExport(format, scope) and the host fetches every matching row (not just this page) and downloads it. A toCsv / toJson helper turns rows and columns into the file for hosts that already have all rows. Disabled while loading or when there are no rows.
