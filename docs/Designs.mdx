# Designs

The design work the library is built from is saved in `designs/` at the repo
root. The files are copies of design canvases: `canvas.json` is the index
(pages, artboard positions, row titles) and each `*.dc.html` is one artboard.
They are for reading, not for editing by hand; re-save from the canvas after
changing it.

| Folder                        | What it is                                                                                                  | Built as                                                 |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| `designs/platform-shell/`     | The platform shell: chat with its own menu, the wizard, the side-menu reference, the rejected revisions     | **Recipes / App shell** and the components it is made of |
| `designs/agentic-flows/`      | The workflow run canvas: horizontal lanes, the flow console, node kit                                       | **Workflows / Recipes / Loan review run**                |
| `designs/responsive-review/`  | The tablet and phone review: which widths are supported, how to decide what gives way, evidence screenshots | Rules every component and recipe follows                 |
| `designs/assistant-greeting/` | The Ghost prompt greeting, its widget and error states, and the Aristotle avatar options                    | **Chat / Components / Conversation**, empty state        |

## Assistant greeting

Two live boards, each one HTML file that opens in a browser. `greeting.html`
is the **Ghost prompt**: a two-tone headline, the assistant typing today's
suggestions into the empty composer (Tab to use one), and Suggested for today
rows with the reason beside each. It also shows the greeting in a floating
widget and a command bar, how a minimized launcher reports a finished task or a
dropped connection, and the start-from questions on hover. `aristotle.html` is
the avatar work: the Bearded face and Marble bust, and two variants of the bust.

Built so far: the full-page empty state (`Greeting`, `SuggestedQuestions` as
rows, the composer's ghost prompt via `useGhostPrompt`), and the assistant's
humanized assistant. The Marble bust won the avatar review: humanized, the
assistant is the bust, otherwise the Orb, and the app turns humanized on for
super admins. `AssistantAvatar` draws whichever the host sets
with `AssistantAvatarProvider` (and `assistantAvatarFor`); avatars for
individual agents are planned. The widget greeting, launcher states and error
handling are still to come.

## Platform shell

The canvas has three pages. The current direction is **Mercury direction 2.0**
(files prefixed `M2`): Mercury-style pages under a navy top bar that carries
the menu toggle, the logo, up to three pinned pages, the tenant switcher, a
search icon, notifications and the account menu.

The boards that drew the old 248px side menu (Spaces and Data groups, chevron
sub-items) have been removed; they are in git history. New designs use the
unified menu, a 68px app rail beside a 260px panel. The boards left are chat
with only its own menu, and the wizard, which hides the side menu.

| Canvas page           | Files     | Status                                                                              |
| --------------------- | --------- | ----------------------------------------------------------------------------------- |
| Mercury direction     | `MWizard` | Second pass. Only the wizard board is left.                                         |
| Mercury direction 2.0 | `M2…`     | **Current.** What the app shell recipe implements. Chat and wizard boards remain.   |
| Component revisions   | `Rev…`    | **Rejected.** A Mercury-style restyle of eight components. Kept for reference only. |

Decisions that came out of the reviews and are easy to undo by accident:

- The tenant switcher lives in the top bar, not the side menu, because a wizard
  hides the side menu.
- A space a tenant does not have is left out of the menu, not shown locked.
- The tenants list sits outside any tenant and is a data table.
- In chat, only the chat's own menu shows (new chat, filters, history), and it
  is resizable by dragging.
- Buttons on the pages are the library's `Button`. The pill buttons in the
  artboards were not carried over.
