Data table, without the caret

The expand caret goes. A row still opens when you click it, and the name is still the real button, but the table now says "open" with the avatar and the rail instead of a glyph in its own column. This file is the design; it is built in src/components/data-table. Below: what the table does today, what is wrong with it, and the proposal, which you can click.

Today

Rebuilt from the ExpandableWithRowActions story at 1120 px wide.

1 2 3 4

    Proposed

    Click a row or its name to open it. Hover a row to reveal its actions, or press Tab: they show on keyboard focus too.

    Proposed, narrow container

    Same table at 600 px. Contact, email and seats drop first; actions stay visible because touch has no hover.

    What changes

    • No caret columnIts 34 px go back to the row. The name button keeps aria-expanded, so assistive tech loses nothing.
    • The avatar marks the open rowIt fills with the brand colour, and a 3 px rail runs down the row and its panel. Selection never uses either, so open and selected stop looking alike.
    • Closed rows say they openOn hover or focus the name underlines. That is the whole affordance; there is no icon to explain.
    • Created is sizedThe last column is no longer whatever is left over after a caret and a three-icon cell. The name column takes the slack.
    • Pills are outlined and small24 px tall, a hairline in the status colour, no fill. That is the library's own Pill with variant="outline" size="sm"; nothing new in the primitive.
    • Sort shows a pair of arrowsOn the sorted column the arrow for its direction is dark and the other is slightly grey. Other sortable columns show the pair, grey, on hover.
    • Actions appear when wantedHover, keyboard focus, an open row or a selected row. Always visible on touch. The header label becomes screen-reader-only.
    • The panel lines up with the tableIts content starts at the name column's left edge, not at an arbitrary 64 px, on a canvas-tone drawer so it reads as part of the row, not a second row.
